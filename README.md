# 🌦️ Weatherly – Modern Weather Dashboard

A modern, responsive, and feature-rich weather application built with **React.js** and **Vite**. Weatherly provides real-time weather information, forecasts, and useful weather insights through a clean, interactive, and user-friendly dashboard.

Whether you want to check the current weather, monitor upcoming conditions, or explore weather trends, Weatherly brings essential weather information together in one place.

## 📌 Project Overview

Weatherly is a frontend web development project designed to make weather information accessible through an intuitive dashboard.

The application allows users to search for cities, view current weather conditions, monitor temperature changes, and explore additional weather-related information.

The project focuses on:

- Responsive user interface design
- Reusable React components
- Interactive dashboard elements
- API-based weather information
- Data visualization
- Modern frontend development practices

---

## ✨ Features

### 🌤️ 1. Real-Time Weather Information
- Displays current weather conditions.
- Shows temperature and weather descriptions.
- Provides additional atmospheric information.
- Dynamic weather icons based on weather conditions.

### 🔍 2. City Search
- Search for weather information by city name.
- Displays weather details for the selected location.
- User-friendly search interface.

### 📅 3. Weather Forecast
- View upcoming weather conditions.
- Monitor temperature variations.
- Plan activities based on forecast information.

### 📊 4. Weather Charts
- Interactive weather data visualization.
- Temperature trend analysis.
- Easy-to-understand graphical representations.

### 💨 5. Atmospheric Information
Provides useful weather parameters such as:
- Humidity
- Wind speed
- Atmospheric pressure
- Visibility
- Sunrise and sunset information

### 🌧️ 6. Rain Tracker
- Displays available precipitation information.
- Helps users monitor rainfall conditions.
- Provides additional insights into upcoming weather.

### 📍 7. Location-Based Weather
- Access weather information using location-based functionality.
- Quickly check weather conditions for your current location, subject to browser permissions.

### 🔄 8. Refresh Weather Data
- Refresh weather information when required.
- Helps retrieve updated weather conditions.

### 🎨 9. Modern User Interface
- Clean and visually appealing dashboard.
- Weather-themed design.
- Interactive icons and components.
- Responsive layout for different screen sizes.
